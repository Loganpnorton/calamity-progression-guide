# Calamity Progression Guide

A standalone interactive progression guide for Terraria Calamity Mode, focused on Melee and Summoner builds. It presents equipment and progression recommendations across Pre-Hardmode, Hardmode, and Endgame, alongside boss tracking and reference links.

## Features

- Browse progression recommendations for Melee and Summoner.
- Filter by game era and search the guide.
- Track defeated bosses, including world-evil selection.
- Keep checklist progress in the browser with `localStorage`.
- View recipe and source references from the guide.

## Run locally

Open `index.html` in a modern browser. The page, styles, application code, font, and bundled item imagery are contained in that file; no package install or build step is required.

## Deploy

This is a static site with `index.html` at the project root. Import the repository into Vercel and use the default static deployment settings. The current production site is [calamityprogression.vercel.app](https://calamityprogression.vercel.app).
